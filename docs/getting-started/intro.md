# Introduction

Welcome to ESW! The Getting Started section is designed to get you up and
running as smooth as possible. It consists of three starter projects to help you get experience with
using microcontrollers and communication protocols, as well as gain familiarity with the tools we use.
There is also useful information linked below to supplement the starter projects.

## ESW Setup
Complete these setup steps before starting the starter projects!

1. [Complete Software Team Setup](https://docs.mrover.org/software/setup/getting-started/)
2. [Clone ESW Repo](https://github.com/umrover/mrover-esw)
3. [Install STM32Cube\* Tools Using ESW bootstrap.sh](stm32cube/index.md)


## Starter Projects

All new members are asked to complete the following starter projects:

1. [Starter Project: LED](starter/led/index.md)
2. [Starter Project: Servo Part 1](starter/servo/part1-pwm.md)
3. [Starter Project: Servo Part 2](starter/servo/part2-can.md)
4. [Starter Project: Temperature and Humidity Sensor](starter/temp-humidity/index.md)

As everyone comes from varying levels of experience, extra information is provided in these docs to
assist the learning process. Please do not hesitate to ask for help!

Some helpful references include:

1. [Intro to Nucleos](../info/nucleos.md)
2. [Communication Protocols](../info/communication-protocols/index.md)
